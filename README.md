# 九重登仙路 · WorkBuddy 实战修炼手册

> 用修仙体系讲明白 WorkBuddy 的小白进阶课。一套可玩的互动游戏、62 篇已开源口播稿和首批 54 张知识卡片，带着你从「第一次听说 AI」走到「用 AI 搭起自己的工作系统」。

---

## 这是什么

很多讲 AI 工具的课，要么把人吓退，要么藏着割韭菜的尾巴。这个项目反着来：

- **不神化**：AI 不是什么魔法，它早就在你手机里（推荐、导航、语音助手）。
- **边界透明**：前三重完整免费；第四重起的完整带练进入付费带练或企业内训，不在游戏里接支付。
- **能动手**：配套一个网页小游戏，你直接在真工具里通关，而不是看别人演示。

作者 Eric，做了十二年工程和研发，现在把「普通人怎么把 AI 助手用起来」这件事，拆成一条能走通的路。

---

## 两条主线

这个项目由两条线组成，互相打配合：

### 一、互动修炼游戏（九重天）

一个零依赖的网页小游戏，把学习路径做成九重关卡：

`启机 → 立契 → 藏识 → 铸法 → 化身 → 渡错 → 成术 → 众智 → 传灯`

前三重提供完整任务、步骤和自证验收。第四至九重只展示进阶说明、能力目标和预期道果；完整步骤进入付费带练或企业内训。游戏不接支付，也不收集报名信息。

`v1.0.0` 的正式游戏文件是 [`game/index.html`](game/index.html)，为零依赖单文件，可直接下载或部署到任意静态托管。前三重练习材料位于 [`practice/`](practice/)；旧 AgentOS 演示地址不代表本版本的商业边界，因此不再列为正式入口。

### 二、实战内容系列（五卷 62 支主线，EP63+ 待规划）

按学习顺序分五卷，每卷都有明确目标：

| 卷 | 主题 | 集数 | 目标 |
|----|------|------|------|
| 卷一 认知篇 | 破除神秘、建立概念 | EP01-06 | 先想通「AI 到底是什么」 |
| 卷二 入门篇·凡躯 | 让小白真正用起来 | EP07-18 | 装好、开口、出第一份成果 |
| 卷三 进阶篇·金丹 | 效率翻倍、自动化 | EP19-32 | 定时任务、批量处理、流水线 |
| 卷四 高手篇·大能 | 工作系统化 | EP33-44 | 技能包、多智能体、个人系统 |
| 卷五 收官+番外 | 变现与外延 | EP45-62+ | 讲出来、用出钱、持续生长 |

完整分集大纲见 [`docs/课程大纲.md`](docs/课程大纲.md)。仓库已经开源 EP01–EP62 口播稿；视频成片与平台发布状态以 [`RELEASE_STATUS.md`](RELEASE_STATUS.md) 为唯一口径。

### 三、横版知识卡片

[`cards/`](cards/) 收录 EP01–EP06 共 54 张知识卡片及可追溯生产文件。全部为 1920×1080、16:9、横版通用型，自动检查与用户视觉审核均已通过。

## 怎么开始

1. **先打开游戏**：下载或打开 [`game/index.html`](game/index.html)，从前三重免费任务开始。
2. **跟着内容通关**：按卷序阅读口播稿；已有公开视频时，再从发布台账进入对应平台。
3. **到小红书打卡**：每过一关，把你的成果发到小红书，关注 **@Eric_网瘾中年_AI探路者**，和一群同样在探路的人互相看作业。

- [`EP14_素材包.zip`](assets/EP14_素材包.zip) 会议纪要练习
- [`EP16_素材包.zip`](assets/EP16_素材包.zip) 批量喂报告练习
