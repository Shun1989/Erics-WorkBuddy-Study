# 九重登仙路 · WorkBuddy 实战修炼手册

> 用修仙体系讲明白 WorkBuddy 的小白进阶课。一套可玩的互动游戏，加 65 支以上的实战视频，带着你从「第一次听说 AI」走到「用 AI 搭起自己的工作系统」。

---

## 这是什么

很多讲 AI 工具的课，要么把人吓退，要么藏着割韭菜的尾巴。这个项目反着来：

- **不神化**：AI 不是什么魔法，它早就在你手机里（推荐、导航、语音助手）。
- **不当小白鼠**：每一步都给你能复用的真东西，不卖课、不堆名词。
- **能动手**：配套一个网页小游戏，你直接在真工具里通关，而不是看别人演示。

作者 Eric，做了十二年工程和研发，现在把「普通人怎么把 AI 助手用起来」这件事，拆成一条能走通的路。

---

## 两条主线

这个项目由两条线组成，互相打配合：

### 一、互动修炼游戏（九重天）

一个零依赖的网页小游戏，把学习路径做成九重关卡：

`启机 → 立契 → 藏识 → 铸法 → 化身 → 渡错 → 成术 → 众智 → 传灯`

每过一关，对应解锁一类实战能力。游戏里能测你的「灵根」（找到最适合你的入手方向），也能看到九重天地图和副本任务书。

**在线玩**：[https://f4a0061fd6ba4365841c118d390e2249.bj6.agentos-app.net](https://f4a0061fd6ba4365841c118d390e2249.bj6.agentos-app.net)

游戏源码在本仓库 `game/` 目录，纯原生 HTML/JS，可直接部署到任意静态托管。

### 二、实战视频系列（五卷 65+ 支）

按学习顺序分五卷，每卷都有明确目标：

| 卷 | 主题 | 集数 | 目标 |
|----|------|------|------|
| 卷一 认知篇 | 破除神秘、建立概念 | EP01-06 | 先想通「AI 到底是什么」 |
| 卷二 入门篇·凡躯 | 让小白真正用起来 | EP07-18 | 装好、开口、出第一份成果 |
| 卷三 进阶篇·金丹 | 效率翻倍、自动化 | EP19-32 | 定时任务、批量处理、流水线 |
| 卷四 高手篇·大能 | 工作系统化 | EP33-44 | 技能包、多智能体、个人系统 |
| 卷五 收官+番外 | 变现与外延 | EP45-62+ | 讲出来、用出钱、持续生长 |

完整分集大纲见 [`docs/课程大纲.md`](docs/课程大纲.md)。

## 怎么开始

1. **先玩游戏测灵根**：打开上面的链接，花五分钟找到你的入手方向。
2. **跟着视频通关**：按卷序看，每支视频末尾都有「掉落物」（一份可复用的模板或套路）和「下集预告」。
3. **到小红书打卡**：每过一关，把你的成果发到小红书，关注 **@Eric_网瘾中年_AI探路者**，和一群同样在探路的人互相看作业。
