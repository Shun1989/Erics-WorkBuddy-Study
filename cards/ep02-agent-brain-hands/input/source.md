## 来源 B：AI Agent 完全指南（按原文顺序摘录）

来源文件：`08_全电脑AI素材归档/Downloads_100个问题/AI Agent 完全指南/AI Agent 完全指南.md`

> 普通的 LLM 只做一件事：你提问，它回答，结束。

> AI 智能体的工作方式不同。它就像你处理困难任务时的实际做法：先规划 → 调研 → 起草 → 自我审查 → 修改 → 重复。

> 这被称为 ReAct 循环：思考 → 行动 → 观察 → 重复。

> 当任务需要以下特点时，智能体就大放异彩：多个步骤、外部信息、迭代和自我修正。如果一条提示就能解决——那就别构建智能体。

> 半自主（中间）：智能体从你定义的工具中挑选，在你设定的防护范围内做决策。

> 每一步都：小、可检查、有明确的输入和输出。

> 防护措施是“智能体说完成了”和“任务真正定稿”之间的质量关卡。

## 编辑边界

- 用“大脑 + 手脚”作为入门类比，不把 Agent 描述成真人或全自主系统。
- “工具、计划、观察、重复”是结构解释，不对应某个当前产品按钮。
- 自主性越高不等于效果越好；本集建议从限定工具、限定边界、人工验收开始。
- 冷面荒诞节点只解释“能行动也会跑偏”，不制造能力承诺。
- 不使用产品截图、精确统计、外部品牌或付费素材。
