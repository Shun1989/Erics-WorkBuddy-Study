# 项目决策记录

## D-001 商业边界

- 状态：已确认
- 生效版本：v1.0.0
- 决策：前三重“启机、立契、藏识”提供完整免费任务、步骤与自证验收；第四重“铸法”起只公开能力目标、剧情摘要与预期道果，完整步骤进入付费带练或企业内训。
- 实现：公开游戏文件不包含第四至九重的步骤、素材、验收清单或证据提示；游戏不接支付，也不采集报名信息。
- 覆盖：本决策取代开源仓库早期“九重全部开放”和“不卖课”的表述。
