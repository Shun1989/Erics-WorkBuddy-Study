# 合规说明（内容边界与红线）

本仓库面向公开网络发布，所有内容遵循以下边界。请贡献者在提交前自查。

## 一、绝不出现的内容

1. **雇主与在研产品敏感信息**：不得出现任何真实雇主名称、在研产品线、真实型号、真实测试数据、内部项目代号。
2. **特定行业红线词**：本系列作者的本职涉及汽车微电机与智能执行器研发，对外内容一律不使用任何具体零部件名称及对应真实产品的型号代号。
3. **第三方未备案品牌**：对外内容不点名任何未在国内完成生成式 AI 服务备案的境外产品，统一以「助手」指代 AI 能力本身。
4. **真实数据**：所有练习素材均为虚构脱敏数据，仅用于教学演示，与任何真实企业、产品或测试无关。

## 二、练习素材包的处理原则

- 仓库 `assets/` 目录下的素材包，全部为**从零虚构**的脱敏版本（中性行业表述，如「微型驱动单元耐久测试数据」）。
- 作者本地确实存在一份内部参考素材，但其中包含在研产品相关命名与数据，**仅作内部参考，绝不进入对外分发**。
- 任何贡献者若想补充素材，必须先脱敏，不得直接搬运真实业务数据。

## 三、表述规范

- 不使用破折号替代标点。
- 不使用空洞套话与抽象黑话（如堆砌概念、过度修饰的句式）。
- 不使用生硬的对比句式堆砌。
- 写人话，像一个有十二年经验的工程师在跟你聊，不像机器在生成文案。

## 四、责任边界

本仓库内容用于教学与经验分享，不构成任何专业建议。使用者将教程方法应用到自己的工作环境时，应自行遵守所在单位的保密与合规要求。

如发现任何疑似越界内容，欢迎在 Issues 中指出，维护者会第一时间处理。

## 五、v1.0.0 已接受风险

维护者已明确决定：v1.0.0 不修改现有五个 ZIP 及其内部文件名。部分名称与本说明的行业表述边界存在已知冲突，此项作为已接受风险记录在 `docs/DECISIONS.md`，不应被解读为“命名已经完成合规修复”。真实雇主、客户、项目和在研产品数据仍禁止提交。
