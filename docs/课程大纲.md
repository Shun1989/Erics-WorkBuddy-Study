# 《九重登仙路》课程大纲（五卷 62 支主线，EP63+ 待规划）

本大纲列出视频系列的分卷与分集。每支结构统一：钩子（为什么看）→ 功法核心（讲清楚）→ 副本实战（动手做）→ 掉落物（可复用成果）→ 下集预告。

> 配套互动游戏：[`game/index.html`](../game/index.html)。前三重完整免费；第四重起的完整步骤进入付费带练或企业内训。
